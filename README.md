# بيان — Bayan Translator

إضافة ترجمة عربية للمتصفح (تجريبية)، بواجهة عربية ونافذة عائمة لترجمة النص المحدد، مع ترجمة صفحات المواقع على نهج TWP.

## ماذا تفعل؟

- **ترجمة النص المحدد:** حدد نصًا في الصفحة وافتح بيان لترجمته فورًا.
- **ترجمة الصفحة كاملة:** ترجمة محتوى الموقع مع متابعة الجزء الظاهر أثناء التمرير، والنصوص الجديدة أثناء التصفح.
- **محركات متعددة:** Google وBing وYandex وDeepL (خدمات ويب دون مفتاح API).
- **ترجمة تلقائية اختيارية:** حسب الموقع أو حسب اللغة، مع قائمة **لغات الموقع** وزر إضافة.
- **صوت القراءة:** قراءة الأصل والترجمة حسب المحرك المتاح.

## التثبيت

1. من [Releases](https://github.com/kaser4/Bayan-Trial/releases) نزّل أحدث إصدار.
2. فك الضغط عن المجلد.
3. افتح `chrome://extensions` أو `edge://extensions` أو `vivaldi://extensions`.
4. فعّل **Developer mode**.
5. اختر **Load unpacked** وحدّد مجلد الإصدار.

بعد كل تحديث: أعد تحميل الإضافة من صفحة الإضافات، ثم حدّث صفحات المواقع المفتوحة.

## الخصوصية

- لا تُرسل كلمات المرور أو قيم حقول الإدخال الحساسة.
- تُرسل نصوص الترجمة إلى المحرك المختار (وقد يُستخدم بديل إن فُعّل).
- لا يوجد خادم خاص لبيان ولا تحليلات استخدام.
- تُحفظ التفضيلات وقواعد المواقع محليًا في المتصفح.
