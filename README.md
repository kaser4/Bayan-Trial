# بيان — Bayan Trial

مستودع واحد لنفس المشروع، بإصدارات منفصلة كمجلدات:

| المجلد | الإصدار | الوصف |
|--------|---------|--------|
| `0.8.9/` | 0.8.9 | النسخة الأولى المرفوعة |
| `0.8.12/` | 0.8.12 | ترجمة تبويبات الخلفية + أولوية الصفحة الظاهرة |
| `0.8.13/` | 0.8.13 | استعادة سرعة ترجمة الصفحة الحالية (بدون حدّ شبكة على الواجهة) |
| `0.8.18/` | 0.8.18 | تحديث مستقل: لغات الموقع، كشف أدق، واجهة المصدر، إصلاحات استقرار |

## ما الجديد في `0.8.18` مقارنةً بـ `0.8.13`

- **لغات الموقع:** عرض اللغات المكتشفة في الصفحة مع زر **إضافة** للترجمة التلقائية دون تعطيل أزرار الترجمة/الإيقاف/الأصل.
- **كشف اللغات من الخلفية:** قراءة النص عبر `scripting` مع تخزين مؤقت، دون حجب أوامر الترجمة.
- **كشف أدق بعد الترجمة:** يفضّل النص الأصلي وعلامات السكربت (مثل السيريلي) حتى لا تُعتبر الصفحة إنجليزية فقط لأن الهدف كان English.
- **لغة المصدر في نافذة الترجمة:** إظهار اللغة المكتشفة بالأحمر، مع فصل كلمة **اللغة** عن الاسم والرمز لتجنب اختلاط RTL/LTR.
- **حذف تنويه الإرسال** من قائمة ترجمة الصفحة (بدون إزالة الميزات الأخرى).
- **سرعة الواجهة:** طلبات الصفحة الحالية بلا حدّ شبكة؛ تبويبات الخلفية تبقى محدودة.
- **استقرار:** حماية من `Extension context invalidated` بعد إعادة تحميل الإضافة، وإصلاح أخطاء بناء كانت تمنع تسجيل Service Worker.
